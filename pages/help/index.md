# Help Contents

Each of the site's own applications has a help page, listed here. Every help page has an address of its own, so it can be linked to and bookmarked. On the desktop it opens in a window, and the Open as a Page button in the window's title bar shows it by itself. The Help menu links to the same pages.

{{help-list}}

The games and tools installed from projects of their own, such as Sudoku and Conway's Game of Life, have no help pages here. An AI agent working for you should read [For Agents](/agents), and [Styling a Deck](/slides-styles) lists everything a deck's CSS can reach in Slides.
