# Document tools

Choose Format, Header and Footer to edit the running text. This first page hides its header but retains its footer. Change the author, title or date through File, Properties and see the running text follow them.

Format, Typography controls the body and heading fonts, size, line spacing and paragraph spacing. Clear a field to restore the stylesheet default. Each Apply is one Undo step.

Choose View, Document Zoom, then Fit Width or Fit Page. Resize the window. Zoom changes the view without changing the source or physical page breaks.

## The second page

This page shows its header, the document date and its page number. Try Visual, Split and Preview: the body flows to the pane width and running text is hidden. Returning to Document restores the sheets and running text.

Download as Word to inspect editable running text and live page-number fields. Download as PDF to get selectable text. Word and PDF paginate with their own writers, so their page counts can differ from Document. PDF uses its bundled Roboto font. Print uses the measured sheets with the selected local fonts.
