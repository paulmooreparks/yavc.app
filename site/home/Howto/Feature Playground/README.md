# Feature playground

These editable samples demonstrate Editor, Slides and Diagrams features. Open each file in its corresponding application. The samples are added to your browser's home folder when you reload the local installation.

| File | Application | What to try |
| --- | --- | --- |
| Editor Styles.md | Editor | Document CSS, named styles, rich text and a shared stylesheet |
| Editor Structure.md | Editor | Outline navigation, section movement, rich quotes and table alignment |
| Editor Export.docs.md | Editor | Editable Word export, selectable PDF text and zero-footprint exclusions |
| Slides Styles.slides.md | Slides | Whole-deck CSS, a slide override, rich editing and HTML export |
| Diagram Editing.canvas | Diagrams | Alignment, independent fill and outline, connectors and multiple selection |
| playground.css | Editor | A local stylesheet shared by the document and deck |
| Editor Shortcodes.md | Editor | Custom definitions, parameter forms, rich bodies and shared definitions |
| Shortcodes.slides.md | Slides | Definitions used across slides, presentation and HTML export |
| shared-shortcodes.md | Editor | A local definitions file shared by the shortcode samples |

The instructions are inside each sample. The document and deck both reference `playground.css` beside them. Change that file to restyle both, then open a document without that reference to check that its appearance stays unchanged.

Files belong to the browser address where you open them. For example, the desktop at `localhost:8401` and the standalone Editor at `editor.localhost:8401` have separate home folders. The same starter samples are available at each address, but your edits stay at the address where you make them.

Your edited copies are retained when starter files change. Use Save As to keep another copy before experimenting if you want to preserve the originals.
