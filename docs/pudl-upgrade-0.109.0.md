# PUDL 0.109.0 integration

The team lead took PUDL 0.109.0 on 2026-11-25. It contains the shared edit menu and clipboard accessor that yavc.app requested (pudl issue 41) and the fix that keeps display-only reserved shortcuts (pudl issue 40). Tag `v0.109.0` resolves to commit `f8f7f21ab4479fd5acc5edbe9f8dcc7c13bfb90c`. The downloaded archive matches the published SHA-256 `1dbaf73287c543278e89e992aeb4861f37c9c600c3c8875e1f094783adc2a2fa`, and its checksum sidecar uses LF. The distribution manifest matches GitHub's asset digest `6c61736b62b7ee24a9d63bbf8e0b4455b2f5e417acb3b259b2d1916470f42590`.

All 196 distribution paths match the manifest, and every file matches its byte count, SHA-256 and SHA-384 integrity value before replacement. The whole distribution replaces `web/pudl` together. Thirteen files differ from 0.108.2: `pudl.css` and the source, minified copy and source map of `pudl-combo.js`, `pudl-commands.js`, `pudl-menu.js` and `pudl-menubar.js`. `pudl-0.109.0.json` supplies provenance and file hashes to the distribution test and release-record builder.

Three application changes come with it. The shared clipboard helper in `yavc-util.js` used to treat any `window.pudlClipboard` as a host bridge and then carried text only. PUDL 0.109.0 always defines that accessor, so the helper now sends plain text through it and keeps rich HTML on `navigator.clipboard.read` and `write`, which PUDL's editing guide leaves to the editor (decision 210). `test-context-edit.cjs` installs its fake host clipboard through the documented `setTransport` instead of replacing the accessor, and checks that rich copy in Docs still writes HTML. `test-docs-menu-startup.cjs` no longer allows the four reserved-shortcut warnings and now fails on any PUDL command or menubar warning.

The local gate is `bash scripts/check.sh --since HEAD`, with `test-context-edit.cjs`, `test-docs-menu-startup.cjs` and `test-selection-scroll.cjs` run in Chromium, Firefox and WebKit. The full site and package lists run in CI.
