# The team's backlog

This page lists the defects and gaps the yavc.app team has found and not yet fixed, so that they outlast the chat they were found in. The lead keeps it. An item is added when it is found, with where it came from, and removed by the pull request that fixes it. Larger designs and Paul's open questions live elsewhere: `docs/editor-follow-ups.md` and `docs/waiting-on-paul.md`.

## Other applets

- **Back reloads the desktop page once the launcher has been opened.** Closing the About dialog, or going Back from a launcher category, returns to the launcher's address and the whole page is then loaded again, so every open window is drawn afresh. PUDL's regions module compares the address without its window fields with the one the page was drawn for, and the launcher's `start` and `start-mode` fields make the two differ. The page has no regions, so the module loads the address (`pudl-regions.js`, the `popstate` listener and `swap`). Seen in Chromium and WebKit with PUDL 0.112.0. `test-launcher.cjs` waits for that load in two places and will time out there when this is fixed; its comments say so. Found on 2026-11-28 while tracing the launcher test's lost execution context.
- **A change to a settings file that arrives while a save of it is under way is dropped.** `config.js` `watch()` returns when `saving` is set and does not read the file again afterwards, so a change made elsewhere during a save is not seen until the next change. Barcode Tool (decision 161) reads such a change when the save is done, and `config.js` should too. Found by Yavc.App Builder on 2026-11-14.

## Diagrams

- **Closing a Diagrams window while the language service is still starting rejects with an error nobody handles.** The language-service bridge's start is rejected with `{code: -32800, message: "Language session ended."}` and the rejection is not caught, so a closed window leaves an unhandled rejection in the console. It should be handled quietly, as a start that was cancelled. Found by Dinah Team Lead on 2026-11-14.

## WebKit failure of test-docs-structure.cjs on Linux, left open for v0.2.120 by Paul's decision (2026-11-26, closed in v0.2.121)

Open defect. On pull request 282, CI's WebKit run on Linux failed `test-docs-structure.cjs` three times on head 396a82f with "createTreeWalker root must be Node", and the same test passes on master in the same CI. The table correction therefore causes it, though the part responsible is not yet known. The test passes on Windows in Chromium, Firefox and WebKit. Paul decided on 2026-11-26 to release v0.2.120 with this check open because the correction works on Windows, where GK Companion draws with Chromium through WebView2. WebKit is also the macOS engine, so until the cause is known the failure may affect Mac users as well as Linux. On head 7ca4c00 the test reported what the page held: after the table was filled in, Ctrl+End and typing "See the site for details." produced no new paragraph after the table, and the page ended with the table. The likely cause is the new rule that makes a too-wide table on a reading page its own scrolling box (`display:block; overflow-x:auto` on the table), which may change where WebKit puts the caret at the end of the document. A CI run on a probe branch without that rule passed the WebKit check, which confirms the cause. The fix for v0.2.121 keeps the scrolling box only on pages that cannot be edited (Preview and the reading page); in Visual a too-wide table scrolls the pane sideways and the paragraphs still wrap at the pane. Closed: CI passed WebKit on pull request 283, released as v0.2.121 on 2026-11-26. Owner: Yavc.App Team Lead.
