# Handoff of 14 November 2026

This note records what the builder shipped from v0.2.88 to v0.2.97, the contracts that changed, and what is still open. It replaces the earlier handoff as the one to read first. The backlog in [backlog.md](backlog.md) and the numbered decisions in DESIGN.md are the sources for detail, and this note only points to them.

## Where things stand

Main holds v0.2.96 and the merges after it up to pull request 239. Pull requests 240 to 247 were approved and queued for v0.2.97 when this was written, stacked in that order on one another, each with main as its base, and each carries the ones before it. Decision numbers run to 195 and the Docs version is 1.37.52 at the top of the queue.

## What shipped

- **v0.2.88.** The Docs-only content package (decision 165), the person-routes contract, direction taken from each block's first strong character (155), hard breaks, the draft notification in the recovery contract, a Content-Security-Policy test, and the team backlog.
- **v0.2.89.** Host shortcodes laid out across pages as frames and flowing blocks (169), print and export of host-drawn shortcodes, with a lasting refusal notice and Try Again (171, 172), Word and PDF export kept in the Docs profile (165), and a Document view that settles without measuring against its own gaps (167).
- **v0.2.90.** Split shows the caret of each pane in the other (168, 174).
- **v0.2.91.** A read-only Docs instance with its own bar and no PUDL toolbar, so disposing leaves no observer, and a click that waits for the layout (176).
- **v0.2.92.** `insert@1` with a plain format (177), a style nonce that the host gives and Docs and CodeMirror use (178), and an action addressed to one instance by event.
- **v0.2.93 and v0.2.94.** `find@1` and the tab tooltip (180), and print of a note whose diagrams the build omits, with `print@1` rejecting when nothing printed (181).
- **v0.2.95.** The reveal of a Split suggestion selects its range in the text (182), and rows with a list in a cell are cut between the items (183, 184).
- **v0.2.96.** Docs menus on every page, as the host's menu bar or Docs' own bar (185), a rule from `---` and Enter (186), and link reference definitions hidden in the page view (187).
- **Queued for v0.2.97.** Go, C, C#, Python and JavaScript colouring (188, 190), print's too-tall refusal as a lasting notice (189), Control+End and Control+Home past a table and a writer fix for a block typed before the first block (191), PDF refused for right-to-left text with a Print button (192), the settings watcher and a change read after a save (193), the language session closed during its start (194), and `placeUsed` for a read-only instance (195).

## Contracts that changed

- **docs/editing-settings-contract.md.** The read-only instance, `insert@1` formats, the style nonce, running an action on one instance, finding words, where the menus are, the `fileCommands` and `save` settings, and now `placeUsed` with the `yavc-docs-place` event.
- **docs/host-shortcodes-contract.md.** Frames, flowing blocks, pieces and how a host's drawings print.
- **Docs actions.** `position@1` is a pure read and returns `placeUsed`, `print@1` rejects when nothing printed, and `find@1` is new.
- **The language table.** `apps/md-editor/languages.js` is the one list of languages, with one grammar script each built by `language-service/build.mjs`, and JavaScript comes from the CodeMirror bundle. Build instructions are in the vendor `BUILD.md`.
- **`config.js`.** Its watcher was never installed before decision 193, so settings now follow a change made in another tab, and they are read only for a `settings` change.
- **The Go writer.** A block with an empty gap that is no longer first is separated by a blank line.

## What is still open

The list is [backlog.md](backlog.md), and it holds only open work. At the time of writing it names these.

- Typing right-to-left text is not tested, and a paragraph's direction cannot be set by hand.
- An undo in the page view that took back nothing could not be reproduced, and it is kept open until the draft-notification test has run many times on main.
- In WebKit the Document view takes 19 to 24 seconds to settle on a long document with rows taller than a page.
- A table or a code block in a cell cannot be cut inside a row, so such a row taller than a page is refused on the page and in print.
- Some tests are flaky or fail on main in Firefox, and the backlog lists them.
- PUDL's toolbar has no teardown, so each editable instance leaves two observers after it is disposed.
- Not started from the language design (docs/language-packs-design.md): the pack manifest, worker and native language servers, colouring of the rendered page, and the wider protocol features. Paul's decision of 14 November limits the first step to colouring.
- Not built: right-to-left layout in PDF export (decision 192 records why).

## Working notes

- A package test needs a full content package built with `go run ./cmd/yavc-content -out <new folder>`, and the folder must not exist. The Docs profile test needs `-profile docs`. Rebuild `apps/md-engine/yavc-md.wasm` first in a worktree, or the engine is stale.
- The CodeMirror bundle is rebuilt only from a fresh `npm ci` of the pinned `package.json` outside `apps`, with `YAVC_LSP_BUILD_ROOT` set. An older install of `@codemirror/legacy-modes` that was missing most modes did not build the grammars.
- A stacked pull request keeps its base as main. After a merge of the one under it, expect conflicts only in DESIGN.md, the applet versions and the test lists.
