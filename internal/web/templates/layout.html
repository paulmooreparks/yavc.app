    Welcome to {{.Site}}

    Pick an application from the list and it opens as a floating window. Drag it by its title bar, resize it from any edge, snap it against the sides, or maximize it; open several and switch between them from the taskbar below.

    Every application also runs on its own, at its own address, with the same game or document you left on the desktop. The ↗ button in a window's title bar takes you there.

    The arrangement of windows lives in the page address, so it can be bookmarked and shared, and Back undoes the last thing you did.

    This desktop is built with PUDL, the Pleasantly Usable Design Language. Skins and colours are in the View menu.

              About yavc.app

              yavc.app is a desktop of applications, and every one of them also runs on its own at its own address, with the same game or document you left on the desktop. The name stands for "Yet Another Vibe-Coded", said with a straight face, since the applications are developed agentically, from written designs and with review.

              The desktop, the windows and every control are PUDL's. Each application is a PUDL applet package, installed by copying its folder in, and most come from repositories of their own.

              What this site keeps for you, your appearance and each application's state, lives under an anonymous session; Settings says more and can forget it. Files you make are kept in your browser, not on this site, and Settings says what that means.

              The code is at github.com/paulmooreparks/yavc.app.

              About PUDL

              PUDL, the Pleasantly Usable Design Language, pronounced "puddle", gives every affordance one visual representation: what can be pressed is raised, what takes input is sunken, and what is read is flat. Somebody who has learned it once can use any application built with it.

              Its web implementation is a stylesheet, a small theme script and a font, with optional scripts for menus, floating windows, applets and the rest, and no framework. Skins change the shape and depth of every control, and colour themes change the palette, in light and dark.

              This site uses PUDL {{.PUDLVersion}}. The code and its reference page are at github.com/paulmooreparks/pudl.
